# V5 — Connected Cities

MetroForge V5 adds destination-based road vehicles, bridges, road upgrades, wind power, high-density zoning, district naming and local policies, abandoned-building pressure, property inspection, a mayor adviser, population history, pan/zoom controls, mobile panel navigation, portable JSON saves, and V4 migration.

The renderer caches static map drawing, the dashboard refreshes at 4 Hz, road connectivity uses an indexed queue, services use precomputed coverage fields, and route creation is limited to at most one search per 150 ms. Vehicles move using elapsed time rather than frame count.

## Correctness changes

- All four map edges provide external road access.
- Zone access is calculated after the entire road network is marked, fixing scan-order errors.
- Disconnected services and generators cannot supply city service coverage or utilities.
- Undersupplied zones cannot randomly develop new buildings.
- Road removal invalidates vehicles and coverage immediately.
- Service budget no longer changes road and zoning upkeep.
- Demolishing a bridge restores its river tile.
- Saves are validated before replacing the city, and user-controlled names render as text.
- Loading preserves building levels without a random growth tick.
- Loaded pause and speed controls match the simulation state.
- Storage failures leave export available and display a clear message.
- Mission changes are synchronous, so an old delayed callback cannot modify a newly loaded city.
- All city information, budgets, and policies are accessible on mobile.

## Validation

Run `npm test` for connectivity, pathfinding, coverage, malformed saves, and V4 migration regression tests. Browser testing should cover new city, showcase, painting, bridge removal, pause, camera, overlays, mobile panels, save/load and file import/export.

## Limits

48×30 tiles, Canvas 2D, simplified city-wide utilities, aggregate road-capacity congestion, and connected transit capacity. This is an original browser simulation rather than a reproduction of Cities: Skylines.
