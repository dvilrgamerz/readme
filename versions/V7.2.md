# V7.2 — Full-Size Regions & Building Moves

Every plot is now a complete 64×40 map. Sixteen plots form a 256×160 region containing 40,960 tiles. New cities begin in A1 at a useful building zoom. Expand city zooms out to the regional view; Build in this plot returns to a close-up of an owned plot. Zoom can increase further for precise touch placement.

Free build adds a Move buildings tool. Drag an existing building, or tap it and then tap empty land. A ghost preview shows valid and blocked destinations. Escape, right-click or changing tools cancels. Drops onto water or occupied tiles leave the source intact. A valid move keeps the building's level, density, age and inventory. Bus routes and incident locations follow relocated properties; traffic trips affected by a move are safely cancelled and redispatched, with reserved goods returned first. Roads and rail remain in place.

In Free build, moving into a distant plot claims a contiguous path of plots for free. Normal construction continues to use owned land. Roads and utilities must connect at the destination for a moved building to operate.

The renderer draws visible plot caches into a fixed-size viewport instead of allocating a giant world-sized canvas. Empty terrain and properties use compact regional save records. Existing 48×30 and 64×40 cities migrate into A1, preserving buildings and signal locations while making fifteen additional full maps available. The fifteen prepared city designs also start in A1.

Thirty Node tests cover simulation, regional geometry, compact save round trips, validation, legacy migration, move state preservation, blocked drops, free land claims and route/incident relocation. Chromium checks desktop dragging, mobile tap-to-move, region navigation, save/load and active-city frame timing.
